# PHEA-ATLAS AI — Machine Learning Data and Resources

## Overview

This directory contains machine-learning datasets, data-processing resources, model-development files, and related materials associated with the PHEA-ATLAS AI project for high-entropy alloy (HEA) phase-stability screening.

## Project Scope

PHEA-ATLAS AI explores machine-learning-assisted screening of high-entropy alloy compositions using composition-related features and thermodynamic or physical descriptors.

## Repository Contents

Depending on the files included, this directory may contain:

- Raw and processed datasets
- Feature-engineering and data-preprocessing scripts
- Training and testing datasets
- Model-training and evaluation notebooks
- Feature-importance and interpretability analyses
- Model performance metrics and evaluation results
- Dataset documentation and data dictionaries
