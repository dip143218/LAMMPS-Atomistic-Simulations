# Equiatomic Alloy Simulation

## Overview

This directory contains LAMMPS simulation files associated with an equiatomic alloy system.

## Contents

- Input scripts and simulation configuration files
- Atomic structure and configuration files
- Potential files required to run the simulation, where redistribution is permitted
- Log files and selected simulation outputs
- Analysis scripts and derived data, where available

## Reproducibility

Please consult the input scripts, potential-file documentation, simulation parameters, and associated research paper to understand the simulation setup and reproduce the calculations.

## Notes

The exact alloy composition, interatomic potential, boundary conditions, and simulation conditions should be documented based on the files used in the actual simulation.
